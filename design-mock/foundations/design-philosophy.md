# UX哲学

## わたしたちが大事にすること

1. **迷わせない** — 1画面1目的。ユーザーが次に何をすべきか常に明確にする
2. **待たせない・驚かせない** — 状態変化は必ずフィードバックする。破壊的操作は必ず確認を挟む
3. **読ませすぎない** — 文は短く。詳細は「もっと見る」の先へ
4. **誠実である** — 打ち消し表現で不利な条件を隠さない。料金・制約は先に見せる

## 画面設計の順番（デザイナーの頭の中）

1. この画面の主目的（ユーザーが達成したいこと）を1文で書く
2. 主目的のためのプライマリアクションを決める（Button primary はこれ1つ）
3. 判断に必要な情報を重要度順に並べる
4. 空状態・エラー状態・ローディング状態を決める
5. 最後に装飾を考える（多くの場合、追加の装飾は不要）
