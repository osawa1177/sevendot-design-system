# Accordion

見出しをクリックして内容を開閉し、長いコンテンツを折りたたむUI。

## デザイナーの判断基準

- 既定は単一展開（1つ開くと他が閉じる）。並列に見比べる必要があるときだけ `multiple` を使う
- 見出しは内容が推測できる名詞句にする（「配送について」「返品ポリシー」）。「詳細はこちら」など中身が分からない語は避ける
- 開閉状態はシェブロンの回転（開いた時 `rotate-180`）で示す。プラス／マイナス記号との併用はしない
- FAQや補足情報の整理に使う。フォーム入力の必須ステップを隠す用途には使わない（隠れた必須項目は見落とされる）
- パネルには `role="region"` と `aria-labelledby`、ボタンには `aria-expanded` / `aria-controls` を付ける

## 例

```tsx
<Accordion
  items={[
    { id: "shipping", title: "配送について", content: "ご注文から3営業日以内に発送します。" },
    { id: "return", title: "返品ポリシー", content: "到着後7日以内であれば返品できます。" },
  ]}
/>
```
