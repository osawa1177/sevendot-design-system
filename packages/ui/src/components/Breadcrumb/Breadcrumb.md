# Breadcrumb

現在地の階層と上位ページへの導線を示すナビゲーション。

## デザイナーの判断基準

- 階層が2段以上あるページでのみ使う。トップ直下の1段だけのページには置かない
- 要素数は最大4〜5個。深い場合は中間を省略し「ホーム / … / 現在」の形にする
- 最終要素（現在地）はリンクにせず `text-neutral-900 font-medium`、それ以外は `text-neutral-700` のリンク
- 区切り文字は「/」1種類（`text-neutral-500`）。「>」や「»」など複数種を混在させない
- ラベルはページタイトルと一致させる。「戻る」などの動作語は入れない

## 例

```tsx
<Breadcrumb
  items={[
    { label: "ホーム", href: "/" },
    { label: "製品", href: "/products" },
    { label: "デザインシステム" },
  ]}
/>
```
