# Pagination

一覧を複数ページに分割し、ページ間を移動させるナビゲーション。

## デザイナーの判断基準

- 表示するページ番号ボタンは最大7個。それを超える場合は中間を「…」で省略し「1 … 4 5 6 … 20」の形にする
- 現在ページは `bg-primary-600 text-white`、他は `border border-neutral-200`。現在ページはクリック不可の見た目にする必要はないが色で明確に区別する
- 前後の矢印ボタンは端（1ページ目・最終ページ）で `disabled`。矢印は必ず `aria-label`（「前のページ」「次のページ」）を付ける
- 総ページ数が1のときは表示しない判断も許容する
- 無限スクロールで代替できる一覧（フィード等）には使わない。件数と現在地を明示したい表・検索結果に使う

## 例

```tsx
<Pagination
  page={4}
  totalPages={20}
  onChange={(p) => setPage(p)}
/>
```
