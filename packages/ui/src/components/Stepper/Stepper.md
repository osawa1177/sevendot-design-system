# Stepper

複数段階の手続きの進捗と現在地を示すナビゲーション。

## デザイナーの判断基準

- ステップ数は3〜5個が目安。2個ならStepperを使わず単純な前後導線にする。6個以上は工程の再設計を検討する
- 完了ステップは `bg-primary-600` にチェックアイコン、現在ステップは `border-2 border-primary-600` の数字、未完了ステップは `bg-neutral-100 text-neutral-500` の数字で3状態を明確に分ける
- ステップ間のコネクタは完了区間のみ `bg-primary-600`、未完了区間は `bg-neutral-200`
- ラベルは工程名を体言止めで簡潔に（「配送先」「支払い」「確認」）。説明が必要なときだけ `description` を添える
- 現在ステップには `aria-current="step"` を付ける。ユーザーが任意の順で戻れる場合を除き、未来のステップはクリック導線にしない

## 例

```tsx
<Stepper
  current={1}
  steps={[
    { label: "配送先", description: "お届け先の入力" },
    { label: "支払い" },
    { label: "確認" },
  ]}
/>
```
