# Tabs

同一階層のビューを切り替えるナビゲーション。

## デザイナーの判断基準

- タブは**同じ対象の別ビュー**に使う。別のページへの遷移にはタブを使わない
- タブ数は2〜5個。6個以上必要なら情報設計を見直す
- ラベルは名詞・2〜6文字目安（「概要」「料金」「レビュー」）
- 選択状態は下線＋色。背景塗りつぶしのタブ（pill型）はフィルタ用途に限定

## 例

```tsx
<Tabs
  items={[
    { id: "overview", label: "概要" },
    { id: "price", label: "料金" },
    { id: "review", label: "レビュー" },
  ]}
  defaultValue="overview"
/>
```
